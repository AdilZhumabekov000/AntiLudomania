# AntiLudomania
Interactive educational web application about gambling risks, financial losses, and harm reduction. Built with React, TypeScript, Vite, and Three.js.

## About the project

The website begins with an interactive cup-selection game.

The user completes three rounds:

- Round 1 — 5 cups
- Round 2 — 3 cups
- Round 3 — 2 cups

The final round demonstrates a situation where a correct choice does not exist. This is used as an educational example of how gambling can create an illusion of control and encourage repeated participation.

After the game, the user is shown educational information about gambling worldwide and in Kazakhstan.

The website then provides a personal spending calculator that estimates gambling-related expenses over different periods of time.

## Main features

- Interactive 3D cup game
- Three game rounds
- Animated cups and camera movement
- Educational gambling facts
- Kazakhstan-specific information
- Personal gambling spending calculator
- Daily, weekly, monthly and yearly expense calculations
- 5-year and 10-year projections
- Decision-based navigation
- Harm-reduction recommendations
- Responsive web interface

## Spending calculator

The calculator allows the user to enter how much they usually spend on gambling and how often they spend it.

The website then calculates estimated expenses:

- per day
- per week
- per month
- per year
- over 5 years
- over 10 years

The purpose of the calculator is to make repeated gambling expenses easier to understand in long-term financial terms.

## Harm reduction

The website includes practical steps that may help reduce access to gambling, including:

- removing gambling applications and bookmarks;
- disabling gambling-related notifications;
- making access to money more difficult;
- using spending and transfer limits;
- using self-restriction tools;
- speaking with a trusted person or professional if stopping becomes difficult.

## Purpose

The project was created as an educational and preventive web application.

Its goals are to:

- increase awareness of gambling-related risks;
- demonstrate the illusion of control in gambling;
- show how repeated expenses accumulate over time;
- encourage users to reflect on their gambling behaviour;
- provide practical harm-reduction information.
